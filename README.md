# 🌐 Portfolio Website

A modern, responsive personal portfolio built with **HTML, CSS, and JavaScript**.  
It showcases projects, skills, education, and contact details with smooth navigation and interactive UI elements.

---

## 🚀 Features
- Fixed header with navigation bar
- Mobile-friendly menu toggle (hamburger → close icon)
- Smooth scrolling between sections
- Active link highlighting while scrolling
- "Back to Top" button with smooth scroll
- Responsive design for desktop, tablet, and mobile
- Clean dark theme with gradient highlights

---
